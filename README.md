# 🐶 TinDog – Frontend Web Project

TinDog is a fun and responsive frontend web application inspired by the idea of connecting dogs with their perfect companions. This project focuses on building a clean UI using Bootstrap components while ensuring responsiveness and smooth user experience.

---

## 🛠️ Tech Stack
- HTML
- CSS
- Bootstrap

---

## ✨ Key Features

- 📱 Fully responsive design using Bootstrap grid system  
- 🎨 Clean and modern landing page UI  
- 📦 Structured sections (Hero, Features, Pricing, Testimonials)  
- ⚡ Reusable Bootstrap components for faster development  
- 🎯 Focused on layout, alignment, and visual hierarchy  

---

## 💡 What I Learned

While building this project, I focused on improving my frontend fundamentals:

- Understanding Bootstrap grid and layout system  
- Using pre-built components effectively  
- Maintaining consistency in UI design  
- Structuring a complete landing page from scratch  

---

## 📌 Sections Included
